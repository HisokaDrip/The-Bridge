Bridge is a lightweight tool that lets you easily connect your mobile device to your PC.
It acts as a simple “bridge” between the two devices, allowing you to connect and control your pc from the mobile
you can:shutdown,sleep,share files between pc and mobile blah blah etc


## config
set a `SECRET_KEY` env var before running (see `.env.example`). if it is not set, a random key is generated each start, which is fine for local use.
